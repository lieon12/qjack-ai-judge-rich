# ai-judge-rich-01 — Shopify teardown reports for pet-supply stores

Entry for make.fun's "Make the AI judge rich": a Python program that writes one
947-character plan to `/output/entry.txt`. The plan has an AI agent sell
one-page Shopify teardown reports to pet-supply store owners for $39 each —
auditing 40 stores a day by code, emailing each owner their biggest leak free
as the sample, and delivering each paid teardown within 24 hours — with honest
expected money of about $390 in 30 days, no human doing the work.
